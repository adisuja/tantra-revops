The Segment Map

One invite for a whole list reads like it was written for nobody. Sort the list into segments first, then write one invite per segment. AI does the reading and the sorting. It does not write a new message for every person.

The five steps, in this order

1

One list first

Merge every source into one list before anything else: your CRM, your LinkedIn searches and past registrants. Remove duplicates by email.

2

Read every buyer

AI goes through each company's website and the person's recent posts, so one buyer stops looking like the next.

3

Sort each buyer into a segment

Each person gets the segment their invite is written for: by role, by kind of company, or by what just changed for them.

4

One invite per segment

Same event, same link. Only the first line and the example change by segment.

5

Merge fields only

First name, company, role. AI reads and sorts; it never writes a new message for every person.

Before you send

  • I checked the first 25 sorted rows. A pattern of misses means I fix the rule, not the rows.
  • Every merge field is spelled exactly as my sending tool expects.
  • Each person sits in one segment only, and gets one invite.
  • Anyone who says no comes off the list for good.

The Segment Map

Prompt 1: sort the list

Sort my list into segments
YOUR TASK
Sort every buyer in the list below into one of my segments, so each segment can get its own invite.

THE FACTS TO USE
My segments: [FILL: segment name, who is in it (role and kind of company), and what just changed for them, one line each]
My fit rules: [FILL: who must be in the list, who must never be]

RULES
- Read each company's website and the person's recent posts before you sort them.
- One segment per person. If nobody fits, write NONE and the reason. Never guess.

WHAT TO RETURN
A table: first name, company, role, segment, one-line reason.

CHECK BEFORE YOU ANSWER
Every row has exactly one segment or NONE. No row has a made-up fact.

THE LIST
[PASTE: first_name, company, website, role, linkedin_url]

Prompt 2: one invite per segment

Write one invite per segment
YOUR TASK
Write one invite for each of my segments, for [FILL: my event line or offer].

THE FACTS TO USE
My segments and what each one cares about: [FILL]
What they leave with: [FILL]

RULES
- Use merge fields only: {first_name}, {company}, {role}. Write sentences that still read well if {company} is empty.
- One invite per segment, not one per person. The segment changes the first line and the example, nothing else.

WHAT TO RETURN
For each segment: the title or subject line, the first two lines, then the rest.

CHECK BEFORE YOU ANSWER
Each invite names its segment's own problem in line one. Each one has the same link and the same date.
