The Omni-Channel Outreach System

Email, LinkedIn, calendar invites and WhatsApp, run as one conversation per buyer. Not four tools sending four different messages to the same person.

The rules that make it one conversation

1

One sequence holds email and LinkedIn

Steps run in your order, so a buyer meets one story. Invites run beside it as their own campaign.

2

One owner per prospect

Split the list by job title so each person hears from one sender.

3

A reply stops everything

Any reply on any channel ends the sequence and a person takes over.

4

Each channel gets its own tagged link

So you can see which channel earned each sign-up.

5

Start with two channels

Cold email plus LinkedIn. Ads only once your page converts.

The prompt that writes the email steps

Write my cold email thread
Write a 5-step cold email thread inviting [FILL: buyer role] to [FILL: my event line, resource or offer].
Two versions with the same offer: A leads with the outcome; B leads with this objection in my buyer's words: "[FILL: objection]".
Step 1 on day 0 has a subject line (under 6 words, plain, no hype). Steps 2 to 5 (days 3, 6, 9, 13) are replies in the same thread: under 80 words each, one new reason each, one link only.
Merge fields allowed: {first_name}, {company}. Last line of every step: a one-line opt out.
Use my Funnel Brief. No invented numbers, names or results. If a step needs proof and I have none, write it without proof.

Never

  • Send cold outreach from your main domain.
  • Message someone on WhatsApp who didn't opt in.
  • Run two separate campaigns at the same person at once.
