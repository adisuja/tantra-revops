The 12-Stage Pipeline Clock Sheet

A deal doesn't need a no to die. It only needs to wait. Give every stage a time limit, one owner and a next step for when the clock runs out.

Blank cells are yours to set. Every clock already filled in is the one we teach.

How to fill it in

1

Spell the stage names once

Use the same names in your CRM and never rename them. A renamed stage breaks every automation that moves a contact into it.

2

Put one name in every Owner cell

One person, not a team. Nobody owns a wait that belongs to everyone.

3

Give every sequence one exit rule

A reply, a booking or a stage change removes the contact, so nobody gets chased after paying.

4

Build the booked-call reminders first

If you build only one sequence today, build that one.

The prompt that writes the messages

Write my pipeline follow-ups
Write the follow-up messages for every stage of my sales pipeline: form filled, call scheduled, no show, qualified, unqualified, call held, follow-up, proposal sent, proposal accepted, payment completed, onboarding, delivery.
For each stage: the trigger, the exit, a table of steps (offset, channel, owner, purpose) and the full copy. Email: subject, preheader, body. SMS: under 160 characters. WhatsApp: under 400 characters. Call steps: a 3 to 5 line script.
Fields: {first_name}, {booking_link}, {meeting_link}, {reschedule_link}, {invoice_number}, {amount}, {due_date}, {payment_link}, {expiry_date}.
Only facts from my Funnel Brief. Where a fact is missing, leave a {placeholder}. No invented results.
